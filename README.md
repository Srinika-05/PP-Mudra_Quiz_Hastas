What is it? 

This is a Bharatanatyam (Indian classical dance) quiz which is still in progress. It is to help people practice and memorize the hand gestures 
for two basic beginner-level mudras. They are the Asamyutha Hasta and Samyutha Hasta hand gestures. 

How to run it: 

You can easily download it, and upload them to VS Code to run it. It will work on the terminal. 

How to play: 

Press run, and you will get the directions to play. It is a mini - quiz. You are first asked a few questions about Asamyutha Hastas. 
You are given a word or gesture, and you have to type in the meaning. Remember to type in all lowercase letters, without any spelling mistakes. 
After a set of questions, you are given a score based on the number of answers you got correct. Then, you can choose to either take another 
Asamyutha Hasta quiz again, or move onto the Samyutha Hasta quiz. The Samyutha Hasta quiz is still in progress.
